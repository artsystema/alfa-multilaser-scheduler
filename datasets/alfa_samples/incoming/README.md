# Upload printer jobs here

Use **Add file → Upload files** to add an original job or a ZIP of its complete export folder.

Start with one existing working job. Ideally add:

- `A_cube_L1.zip` — one cube assigned to L1.
- `B_cube_L2.zip` — identical geometry and settings, assigned to L2.
- `C_two_cubes_L1_L2.zip` — two cubes, one on each laser.

Add a matching metadata file beside each job using the [metadata template](../metadata-template.md). Preserve original filenames inside ZIPs.

See [sample preparation and Codex handling instructions](../README.md) for the full workflow. No new printing is required.
